# Primary music workspace

Read INSTRUCTIONS.md as the governing project guidance before doing Primary music work.

For creating or revising Primary singing-time slideshows, read and follow
.codex/skills/create-primary-music-slideshows/SKILL.md.

Keep song work in songs/<song-slug>/ and reuse existing lyrics, storyboards, images,
and assembly files. Read the song's HANDOFF.md before starting and update it before
stopping. Record every decision (cast, style, grouping, wording) in storyboard.md in
the same session; a decision that exists only in chat is lost to the next tool. Ask for the actual title when a request still says [song].

When INSTRUCTIONS.md changes, refresh the skill's bundled reference as an exact
copy. Do not independently edit the bundled copy or duplicate the workflow in the
.agents/skills discovery entry point.
