# Image prompts — <Song title>

Paste-ready prompts for the image tool. Each prompt stands alone: it repeats the style tail so a fresh session can generate any image without the storyboard. Attach `images/cast-sheet.png` to every scene prompt once it exists.

## Style tail

Append to every prompt, verbatim:

```text
<medium, proportions, palette, lighting, camera, background limits>. 16:9 landscape.
Keep the bottom third calm and free of faces, hands and key action. No text,
letters or writing anywhere in the image.
```
